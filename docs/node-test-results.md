# Node.js test-suite results

Results of running Node.js v24.21.0's own tests from `test/parallel` against `--node-compat`, with `tests/node-harness/run-node-tests.mjs`. `tests/node-harness/tests.txt` selects every test except those of Node's build tooling, V8's heap and trace tooling, the inspector and QUIC. A test passes if it exits with status 0. Tests that need runtime flags the runtime rejects, child processes, workers, `cluster` or the inspector are skipped without running, and tests that call `common.skip()` count as skipped.

| --- | ---: | ---: | --- |
| The HTTP client | 190 | 0 | Tests run with `--node-http-listen`, so their servers accept connections, and most remaining HTTP failures are on the client side. | Unsupported runtime flags | 0 | 62 | Tests that need a runtime flag the runtime rejects, such as `--allow-natives-syntax` or the permission model's flags, are skipped without running. The runtime gets the other flags with `--allow-node-runtime-flags`. |
| Unimplemented APIs | 482 | 0 | Stubs that throw `ERR_METHOD_NOT_IMPLEMENTED`, such as brotli and zstd compression, crypto keys and ciphers (there is no OpenSSL), `net` IPC paths and `dgram`. The blockers list below names each API. |

| Timing and resource exhaustion | 60 | 0 | Tests that time out waiting for events that never come, and crashes. Each needs a look of its own. |
